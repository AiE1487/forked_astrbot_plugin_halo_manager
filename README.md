## 📖 简介

这是一个专为 [AstrBot](https://github.com/Soulter/AstrBot) 设计的插件，旨在让博主能够通过自然语言与 LLM 对话，完成博客的日常维护工作。

无论你是想快速发布一篇灵感笔记、翻看博客上发了什么、回复读者的评论，还是将手机里的照片传到图床，只需要一句话，AI 就能帮你搞定。支持 **Halo 2.x** 及以上版本。

## ✨ 核心特性

- **📝 AI 写作与发布**：利用 LLM 的能力撰写文章，并直接推送到博客（支持自动生成 Slug）。
- **📚 文章浏览与阅读**：分页列出博客上已发布的公开文章（可按作者过滤，返回文章 ID），AI 可直接读取全文内容。
- **💬 评论管理**：查看最新评论、按文章分页查看评论、回复/发表/删除评论。
- **⚡ 瞬间 (Moment)**：发布瞬间；分页浏览所有人的公开瞬间（支持 全部公开/仅自己/指定用户 过滤）；按 ID 删除瞬间。
- **🖼️ 快捷图床**：发送图片给机器人，自动上传到 Halo 附件库并返回 Markdown 链接。
- **🧭 内置 Skill**：随插件附带 `halo-manager` 技能文件，指导 AI 正确选用工具、传参与确认删除操作。
- **🔐 安全可靠**：基于 Halo Personal Access Token (PAT) 认证，配置简单且安全。

## ⚙️ 配置说明

在 AstrBot 管理面板的插件配置页中填写：

| 配置项 | 说明 |
|--------|------|
| 博客地址 (URL) | Halo 博客的完整访问地址，例如 `http://192.168.1.10:8090` |
| 个人访问令牌 (PAT) | 在 Halo 后台 -> 用户 -> 个人访问令牌 中生成的 Token |
| 文章发送账号 (Owner，可选) | 文章作者使用的 Halo **登录用户名**（不是昵称） |
| 注册瞬间发布与管理工具 | 开启后额外注册发布/浏览/删除瞬间 3 个 AI 工具；需博客已安装并启用「瞬间」(plugin-moments) 插件，发布者为 Token 所属账号。修改后需重载插件 |
| 注册评论删除工具 | 开启后额外注册删除评论 AI 工具（默认关闭）。删除评论会连带删除其下所有回复，需要 PAT 拥有评论管理权限。修改后需重载插件 |

关于「文章发送账号」：

- 留空时，文章作者默认为 PAT 所属账号。
- Halo 的 Console 发布接口会在服务端把作者强制设置为 PAT 所属账号，因此插件会在创建草稿后自动把作者改为该账号；请确保 PAT 拥有文章的读取与更新权限。
- 发布前会校验该账号在 Halo 中是否存在；若填写了不存在或已删除的用户名，发布会被拒绝（否则文章作者将显示为「已删除用户」）。

## 🚀 安装方法

### 方式一：通过 AstrBot 插件市场安装（推荐）

1. 打开 AstrBot 管理面板。
2. 进入 **插件管理 (Plugin Market)**。
3. 搜索 `halo_manager` 并点击安装。

### 方式二：手动安装

1. 下载本插件的版本压缩包（如 `astrbot_plugin_halo_manager-1.4.1.zip`）。
2. 打开 AstrBot 管理面板，进入 **插件管理 → 安装插件 → 从本地上传**，选择该 zip 安装；
   或者解压到插件目录：

   ```bash
   cd AstrBot/data/plugins/
   unzip astrbot_plugin_halo_manager-1.4.1.zip
   ```

3. 在管理面板中重载插件使其生效。

## 🤖 让 AI 能调用本插件（LLM 工具）

插件按 [AstrBot 文档 - 定义 Tool](https://docs.astrbot.app/dev/star/guides/ai.html#%E5%AE%9A%E4%B9%89-tool) 的推荐方式，使用 **FunctionTool 类 + `add_llm_tools`** 在 `__init__` 中注册 LLM 工具，AI 在对话时可自动选择调用：

**文章**

| 工具名 | 说明 |
|--------|------|
| `publish_blog_post` | 发布一篇新博客文章 |
| `list_blog_posts` | 分页列出已发布的公开文章（每页 4 条，返回文章 ID）。`owner` 参数：留空或 `all`=全部公开（默认）、`me`=自己发布的（优先含草稿）、或填登录用户名=该用户的公开文章 |
| `get_blog_post_content` | 按文章 ID 读取文章正文（Markdown 源文，超 4000 字截断并注明总长） |

**评论**

| 工具名 | 说明 |
|--------|------|
| `get_blog_comments` | 获取全站最新的 5 条评论 |
| `list_blog_post_comments` | 分页列出某篇文章下的公开评论（每页 4 条，返回评论 ID；仅显示已通过审核的评论） |
| `reply_blog_comment` | 回复指定评论（`comment_id` + 内容） |
| `create_blog_comment` | 在指定文章下发表一条新评论（以 PAT 账号身份） |
| `delete_blog_comment` | 删除指定评论（其下回复一并删除；需开启「注册评论删除工具」，且 PAT 拥有评论管理权限） |

**瞬间**（需开启「注册瞬间发布与管理工具」且博客已安装瞬间插件）

| 工具名 | 说明 |
|--------|------|
| `publish_blog_moment` | 发布一条瞬间 |
| `list_blog_moments` | 分页浏览瞬间列表（每页 4 条，返回瞬间 ID）。`owner` 参数同 `list_blog_posts`；`me` 时含自己的私密与待审核瞬间 |
| `delete_blog_moment` | 删除指定瞬间（删除他人的瞬间需要「瞬间管理」角色或超管权限） |

**图床**

| 工具名 | 说明 |
|--------|------|
| `upload_blog_image` | 将图片 URL 上传到博客附件库 |

**启用方式**：在 AstrBot 管理面板中进入 **提供方 / 函数工具**（或 **LLM 工具**）设置，在可用工具列表中勾选上述 Halo Manager 提供的工具并保存。启用后，AI 在回答「帮我发一篇博客」「看看最近评论」「回复评论 xxx」等问题时会自动调用对应工具。

## 🧭 内置 Skill（halo-manager）

插件自带 `skills/halo-manager/SKILL.md` 技能文件，AstrBot 加载插件后会自动将其纳入技能管理（来源显示为插件），内容包括：

- 12 个工具的速查表（用途 / 关键参数 / ID 从哪来）；
- 典型工作流：浏览文章 → 读全文、评论管理（列文章 → 列评论 → 回复/发表/删除）、瞬间管理；
- 约定说明：每页 4 条、`page` 从 1 开始、`owner` 三种取值（all / me / 登录用户名）；
- 错误提示含义（404 = 瞬间插件未装或 ID 有误、401/403 = 权限不足、待审核的含义）；
- 安全规则：**删除类操作必须先向用户复述目标内容并确认后再执行**。

要求：AstrBot **v4.24.2+**；Agent 处于可执行环境（本地管理员或沙盒模式）时技能才会注入对话。可在管理面板的技能管理页中启用/停用该技能。

## 💡 使用指南 (Prompt Examples)

配置并启用 LLM 工具后，你可以直接与机器人对话。以下是一些指令示例：

### ✍️ 发布文章

> **用户**: 帮我写一篇关于“Python 异步编程”的技术博客，重点介绍 asyncio 库，写完直接发布到博客上。

**机器人**: *（思考并写作中...）* 好的，正在发布文章《Python 异步编程入门》...
**机器人**: ✅ 发布成功！链接: https://blog.example.com/archives/python-asyncio

### 📚 浏览文章与阅读全文

> **用户**: 博客最近发了哪些文章？

**机器人**: 第 1/2 页，共 6 篇文章（全部公开）：
· Python 异步编程入门 (ID: python-asyncio) [2026-08-01] 摘要... 🔗 https://blog.example.com/archives/python-asyncio 👀12 💬3
...
💡 如需读取某篇文章全文或管理其评论，请提供对应的文章 ID。

> **用户**: 看看我发过哪些文章。 / 看看用户 zhangsan 发的文章。

（AI 会用 `owner=me` / `owner=zhangsan` 过滤后再列出）

> **用户**: 给我讲讲第一篇文章的内容。

**机器人**: *（调用 `get_blog_post_content` 读取全文并总结）*

### 💬 评论管理

> **用户**: 这篇文章有什么评论？（提供文章 ID 或让 AI 先列文章）

**机器人**: 文章 xxx 的公开评论，第 1/1 页（共 2 条...）：
· 张三: 写得很棒！ (评论 ID: comment-abc) [2026-08-02]
...

> **用户**: 帮我回复张三：谢谢支持，我会继续努力的！

**机器人**: ✅ 回复成功！

> **用户**: 在这篇文章下面发条评论：感谢分享，学到了！

**机器人**: ✅ 评论发表成功。

> **用户**: 删掉张三那条评论。

**机器人**: 确认要删除张三的评论「写得很棒！」吗？（确认后调用 `delete_blog_comment`，需提前开启删除开关）

### ⚡ 瞬间

> **用户**: 发条瞬间：今天天气真好！
> **用户**: 看看最近的瞬间。 / 看看我发的瞬间。 / 看看第 2 页。
> **用户**: 删掉刚才那条瞬间。（AI 会先复述内容让你确认）

### 📤 上传图片

1. **发送一张图片** 给机器人。
2. 紧接着（或同时引用图片）说：

> **用户**: 把这张图上传到博客。

**机器人**: ✅ 图片上传成功！
🔗 链接: https://blog.example.com/upload/2023/10/img.jpg

## ❓ 常见问题 (FAQ)

**Q: 插件支持 Halo 1.x 吗？**
A: **不支持**。Halo 1.x 与 2.x 的 API 架构完全不同，本插件专为 Kubernetes Native 风格的 Halo 2.x API 设计。

**Q: 发布文章失败，提示 401 Unauthorized？**
A: 请检查你的 Token 是否正确，或者 Token 是否过期。建议重新生成一个不过期的 PAT。

**Q: 图片上传失败？**
A: 请确保 Halo 后台的 **附件设置** 允许上传图片，且你配置的存储策略（默认为 `default`）是可用的。

**Q: 文章作者显示「已删除用户」？**
A: 说明文章的 owner 指向一个已不存在的账号（常见于 PAT 所属账号被删除，或配置里填了已删除的用户名/昵称）。可在插件配置中把「文章发送账号」设置为一个有效的 Halo 登录用户名，新发布的文章将以此账号作为作者。

**Q: 发布瞬间失败，提示未找到瞬间接口（404）？**
A: 说明博客尚未安装或未启用「瞬间」(plugin-moments) 插件，请先到 Halo 后台应用市场安装并启用；同时确认插件配置页已勾选「注册瞬间发布与管理工具」（修改后需重载插件）。若提示 401/403，则是 Token 所属账号缺少瞬间发布权限。

**Q: 按「me / 指定用户」浏览文章或瞬间时结果不符合预期？**
A: 过滤使用的是 Halo **登录用户名**（不是昵称）。`me` 模式优先走个人中心接口（文章含草稿、瞬间含私密与待审核），若 PAT 缺少相应权限会自动回退为仅显示已公开内容；指定用户只能看到其公开内容。

**Q: 内置 Skill 没有生效？**
A: 需要 AstrBot **v4.24.2 及以上**；在管理面板的技能管理页确认 `halo-manager` 技能已启用；并且 Agent 需处于可执行环境（本地管理员或沙盒模式），否则技能不会注入到对话中。
